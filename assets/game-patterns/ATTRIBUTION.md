# Game card pattern attribution

The vector glyphs embedded in the SVG files in this directory come from
[Flaticon UIcons](https://www.flaticon.com/uicons), maintained by Freepik Company.

- Source repository: https://github.com/freepik-company/flaticon-uicons
- Source revision: `01c7cf8e403afdf879ff56c99235a34df81db6a2`
- Source font: `uicons-regular-rounded.woff`
- License: https://github.com/freepik-company/flaticon-uicons/blob/main/LICENSE

The glyphs are used as small decorative background elements and are arranged,
scaled, rotated, and given reduced opacity for the game-card patterns. The app
also presents a visible Flaticon attribution link in the settings sheet.

Glyphs used:

- Minesweeper: `bomb`, `flag`, `square-1`, `square-2`, `square-3`
- Checkers: `chess-piece`, `chess-board`, `circle`
- Block Blast: `cube`, `cubes-stacked`, `puzzle-piece-integration`, `grid`
- Sudoku: `square-1`, `square-4`, `grid-dividers`, `square-7`, `square-9`
- Tower: `cubes-stacked`, `layers`, `stairs`, `cube`
- Wordle: `square-a`, `square-r`, `keyboard`, `square-t`, `square-e`
- Monopoly: `dice`, `house-building`, `money-bill-wave`, `key`
